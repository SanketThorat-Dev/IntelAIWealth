# IntelAIWealth

## Project Overview
IntelAIWealth is an AI-powered personal finance intelligence platform.

The system helps users:
- Upload bank statements
- Analyze spending behavior
- Detect anomalies/fraud
- Generate financial insights
- Forecast expenses
- Receive AI-powered financial coaching

---
